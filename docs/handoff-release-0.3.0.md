## Первое, что нужно знать

**Если `xcodebuild` виснет на «Resolve Package Graph» / «Downloading binary
artifact»** — это не сеть и не Xcode. SwiftPM спрашивает у Keychain учётные
данные для хоста загрузки, а показать диалог некому. Лечится одним прогоном:

```bash
cd /tmp && swift build --disable-keychain
```

Артефакт ляжет в общий кэш, дальше `xcodebuild` берёт его оттуда. Подробнее —
`CONTRIBUTING.md`. Не трать на это день, как потратил предыдущий агент.

1. **Гвардия `.`/`:` на заглавную в `TranscriptPolisher` остаётся.** Она и
   модель спанов фильтруют по разным осям: гвардия смотрит, что *после* знака

   является токен*. Удалить её, «раз теперь есть спаны», — соблазнительная

2. **Точная замена идёт до детекции спанов.** Это и есть правило «явная воля
   человека выше защиты» — отдельного прецеденса писать не нужно, порядок и
   есть правило.
3. **`generate_keys` на этом проекте не запускается никогда.** Публичный ключ
   вшит в разошедшиеся беты; новая пара навсегда оставит всех установленных
   на старой версии. См. `AGENTS.md`.

## Замеры, которые ждут

Все требуют установленной модели и `asr-bench`. Порог объявляется **до**
замера, а не подгоняется после.

1. **Пунктуация после правки.** Прогнать на **той же группе `long`**, что дала
   423/450 — подменять её другим набором записей нельзя. Место в
   `docs/benchmarks.md` подготовлено, раздел «Пунктуация после подсказчика».
2. **Словарь 52 → 200.** Ступенькой: пилот **+50** → замер на существующих
   чистых корпусах → **95% CI дельты WER (bootstrap) не допускает ухудшения
   >0.2 пп** + аудит ложных срабатываний + проверка кириллических алиасов
   CTC-споттера → расширение до ~200 **только по зелёному**. Комментарии —
   только неочевидным терминам.
3. **Импорт/экспорт словаря.** Построчно «слышится → пишется», last-wins,
   «→» в spoken запрещена, превью ошибок построчно, запись атомарная. Экспорт
   — версионированный JSON без потерь. Гейты: round-trip identity, 100
   терминов ≤1 мин. **CSV срезан** — не возвращай.
4. **Гейты превью (3.6).** Стабильность подтверждённых спанов; покрытие —
   доля подтверждённого фиксируется первым замером и становится планкой;
   CER подтверждённой части и финала — раздельно против референса.
5. **Babble-корпус (3.7) — только корпус и отчёт, детектор не шипится.**
   У приложения нет наблюдаемого сигнала SNR: его знает только микшер, а не
   рантайм. Preflight голосов — **жёсткий фейл**, если `say -v ?` даёт <4
   разных или <2 русских; деградировать корпус запрещено. Предикат пролезания
   заморожен до замера: ≥3 подряд нормализованных контент-токена, которые есть
   только в референсе помехи. Сигналы строятся только при пролезании ≥5% при
   SNR ≤ +5 dB (n≥300); иначе отчёт и стоп.
6. **Bake-off (3.8).** GigaAM v3, Whisper-v3-turbo; Qwen3-ASR только при
   локальных весах, иначе исключить с записью. Манифест на движок + хешированный
   список бустуемых терминов (конфаундер объявляется). **Смена движка по
   синтетике запрещена** — решение предварительное.
7. **EN README и лендинг (3.10).** Клеймы только измеренные: скорость и
   локальность можно, «parity», «SOTA», «25 языков» и сравнения по качеству —
   нельзя.

Всю синтетику помечать `"source": "synthetic"`. **`quality/live-benchmark.json`
не трогать** — он существует ровно чтобы отличать измеренное на людях.

## Публикация

`scripts/release.sh` проверит сам: чистое дерево, ветку `main`, совпадение с
`origin/main`, зелёный CI на SHA, наличие заметок и два человеческих файла.

Что **блокирует прямо сейчас** и чего агент сделать не может:

| Блокер | Кто закрывает |
|---|---|
| Сертификат Developer ID (`security find-identity` → 0 valid) | человек, Apple-аккаунт |
| Профиль notarytool | человек, `xcrun notarytool store-credentials` |
| Интеграция 1Password CLI → `./scripts/bootstrap-release-secrets.sh` | человек, один тумблер в приложении |
| `quality/live-benchmark.json` — живой смоук на 5 голосах | человек, `quality/panel/scripts/` |
| `quality/release-evidence.json` — ручная матрица установки | человек, `docs/manual-check.md` |

Последние два — блокеры **по замыслу**. Они существуют, чтобы отличать
измеренное на людях от измеренного на `say`. Обойти их, подставив синтетику,
нельзя: это ровно та ложь, ради предотвращения которой они и написаны.

Команда выпуска — в `AGENTS.md`.

## Как здесь принято работать

TDD: сначала падающий тест. Политики — чистые `enum`/`struct` с тестами, а не
логика во вью-моделях. Молчаливая деградация запрещена: ошибка видна человеку.
Перед коммитом — `swift test` в обоих пакетах плюс app-тесты; **689 — нижняя
планка**, число обязано расти.

Имена тестов зависят от таргета: в пакетах — английские с русским `///`,
в app-таргете — кириллицей (324 из 324). Смотри соседние файлы.

Комментарий объясняет **почему**, а не что. В этом репозитории почти каждое
правило пришло из замера или из поломки — если пишешь правило, пиши и цену.
