# План: что делаем (без дат — только порядок зависимостей)

Источник: план-ревизия 3 от 05.08.2026 (артефакт: claude.ai/code/artifact/5ff7320b-1ef9-4a86-b758-46d9fa6c0145), консенсус челленджа Codex 10/10 + Kimi 10/10. Всё делается одним заходом; календаря нет — важен порядок. Гейты меняются только вместе с планом.

**Карта зависимостей:** A ни от чего не зависит — запуск №1 едет первым (козыри: латентность + проверяемость, полиш не нужен). C и E ← панели и оси B (старт на синтетике/dev, финальные гейты — на product-панели). E1 ← C3 + D1. Условная ветка: провал смоука A1 (>3 пп mixed) вводит A5 ← E2. Остальное параллелится.

**Статкритерий на всё:** «лучше» = 95% ДИ парной дельты (bootstrap по спикерам) не содержит нуля; guardrail-оси ≥ −0.5 пп; финальные решения — только на замороженной product-панели.

## A · Выпустить приложение
1. Смоук live-benchmark: 5 своих спикеров × `quality/panel/scripts/smoke-{ru,en,mixed}.txt` × 2 микрофона, референсы заморожены до прогона → `quality/live-benchmark.json` → `scripts/validate-live-benchmark.py` зелёный.
2. Release-evidence: матрица 4 окружений + первый appcast item + доказанное обновление 0.1→0.2 → release.sh проходит все гейты.
3. Латентность на витрину: stop→text в HUD; прогресс-бар первой загрузки (сейчас 15.7 с молчания).
4. EN README + лендинг + материалы поста (демо «Wi-Fi off → промпт в Claude Code → ~150 мс»; self-check). Без клеймов parity/SOTA/мультиязычности до зелёного live-benchmark.
5. **ЗАПУСК** Show HN. Условие: 1–4 закрыты; при провале смоука >3 пп mixed — сначала решение по движку (E2).

## B · DictationBench
1. Харнесс: аудио+два голда+скоринг; прогон реального приложения на M4 Mac mini, вставка через AX-observer; 7 осей + privacy-аттестация (Overall / Local-only) → `dictbench run <app>` выдаёт JSON-артефакт с диффами.
2. Панели: product (≥12, внутренняя) и bench (6–8, CC-BY public + hidden), не пересекаются → обе записаны; бюджет $0.8–1.2k.
3. Датасет-пилот: EN 1ч + RU 1ч + CS 0.5ч (первый известный публичный RU-EN CS сет), двойная аннотация, {a|b}; hidden 30 мин = только анти-гейминг → заморожен, IAA посчитан, canary вшиты.
4. Прогон 5 приложений (Handy, Superwhisper, VoiceInk, Apple Dictation, мы hors concours), версии пинятся, вендор-нотис (политика 7 дней), места — только при статзначимой дельте.
5. **ЗАПУСК** Публикация: репо + лидерборд + пост; питч сообществу Handy и HF audio; honest ablations. Наш CI переезжает на оси бенча.
6. v1.0 (контракт сейчас, работа после пилота): 8–10 приложений (+Wispr/Typeless/Aqua), 15–20 спикеров, датасет растёт из пилота (~4ч public + 1.5ч hidden, квартальная ротация), 5 прогонов, IAA, 5% аудита judge, hidden у внешнего хранителя → мы в общем зачёте.

## C · Cleanup-модель
1. Порт из WaiComputer: контракт чистки, 28 фикстур + meaning-drift харнесс, typography-fold, learn-from-edits → харнесс гоняется локально.
2. Датасет по Части II (текстовые пары); сплиты и метрики зафиксированы до тренировки; eval — product-панель (← B2).
3. LoRA Qwen3-0.6B и 1.7B (non-instruct, MLX). A/B: Quill-0.8B, VoiceScribe-0.8B, промптовый Qwen3, raw, детерминированный полишер. Гейт: бьёт всех по статкритерию; M4 mini warm p50 ≤400 мс + контрольный замер на M1 рядом с тумблером (иначе 0.6B; не проходит и он — не шипим).
4. Интеграция: докачка 0.4–1.2 GB opt-in, default-on только после гейта; ⌘Z/Fix-окно; faithfulness-guard откат к raw; zero-network гейты зелёные; adversarial-набор в тестах.
5. **ЗАПУСК** Пост «обучили свою модель» с цифрами на своём бенче + HF. Гейт не пройден → публикуем абляцию.

## D · Словарь, биасинг, фичи
1. Словарь v2: bulk import/export, паки (RU-dev до ~200, EN-dev), per-term «не бустить», счётчик → импорт 100 терминов ≤1 мин.
2. Trie-биасинг в декод-цикле + тест кириллических алиасов споттера → tech-term ось растёт; флаг отключения.
3. Prompt Mode и тон по bundle id (verbatim в IDE/терминалах; prose+автотон в чатах/почте; «читаем ровно bundle id») → term-accuracy и backticks ≥99%.
4. История opt-in + единый privacy-контур (два раздельных opt-in: тексты истории / пары learn-from-edits 30 дней; по умолчанию — ничего на диск) + превью-parity (CER ≤5%, автоскрытие; remediation: PR в FluidAudio / пин языка).
5. «Press enter» за opt-in + сниппеты → 0 ложных отправок.

## E · Mixed RU/EN
1. Текстовый путь: глоссарий + cleanup чинят транслит; пунктуационно-безопасный ресорер (423→347 запятых — починить). Условие: C3+D1; fallback при красном C3 — чисто словарный путь.
2. Bake-off: Parakeet v3 / GigaAM v3 / Qwen3-ASR-глоссарий / Whisper-v3-turbo; ≥2ч / ≥12 спикеров product-панели. Условие: B1+B2. Цель: end-to-end mixed ≤15%; недостижение = фейл цели.
3. Babble-guard по SNR/энергии (язык — не сигнал) → abstention-recall ≥90%, false-abstention ≤2%.
4. Остались акустические ошибки → ASR-адаптер (Часть II плана).

**Не делаем:** Windows/Linux · облако · чтение экрана · Apple FM адаптеры · зоопарк моделей · маркетплейсы. В очереди после cleanup-модели: Speak-to-Edit, голосовые команды, Translate, modes, метр персонализации.

**Файрвол:** бенч-данные и голоса панелей — никогда в трейн; реальные часы адаптера — вне обеих панелей; 262 пары WaiComputer — только dev; eval заморожен; canary ловят контаминацию. Детали: `quality/panel/README.md`.
