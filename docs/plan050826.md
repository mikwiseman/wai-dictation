# План исполнения волны 1 (docs/agent-wave1.md)

СТАТУС: ФИНАЛ (v4). Четыре раунда внешней критики: Р1 Kimi 7/10 + codex 4/10 (42 возражения, codex — с проверкой по репозиториям), Р2 6/10 + 6.5/10, Р3 без блокеров (8.5 + 7.5, девять деклараций — внесены), Р4 подтверждение: **Kimi SHIP 8.5/10, Codex SHIP 9/10**. Kimi вызван через Kimi Code CLI (kimi-code/k3, эффорт max), codex — gpt-5.6-sol xhigh с read-only доступом к обоим репо.

## Контекст

Волна 1 = срез борда SOTA-30 (`docs/sprint-sota-30.md`) без GPU-аренды и без живых записей. Исполняет одна агентская сессия на M4 Pro **24 GB**; длинные работы — фоном, с явными пилотами времени/памяти до масштабирования. **Принцип: все гейты волны — синтетические и ПРЕДВАРИТЕЛЬНЫЕ; ничто активное/default-on не включается по синтетике** (чистка opt-in и default-OFF; babble — только отчёт; pressReturn — вне волны). Красный гейт C = пост-абляция, допустимый исход.

**W1. Контракт конвейера (до любых фич).** Таблица стадий с точными входами/выходами и golden-тесты на каждой границе: `парсер команд → словарь (exact → phonetic) → [LLM-чистка: prose и включена] → [сниппеты — стадия зарезервирована, в волне неактивна] → typography-fold (12 симв.) → детерминированный полишер (текущие операции: пробелы/капитализация) → материализация .newLine → вставка`.
**Модель защищённых спанов** (порядок явный — сейчас exact и phonetic живут в одной операции `DictionaryReplacements.swift:53`, её придётся расщепить): `exact-замены → детекция и маскирование спанов (backticks, пути, флаги, CamelCase) → phonetic вне спанов → пересчёт финальных спанов`; пользовательская exact-замена — явная воля и выше защиты, случайное фонетическое срабатывание внутри спана — авария. Learn-from-edits никогда не строит предложения из текста внутри спанов. Гейт: спаны байт-в-байт через все стадии после словаря; в корпусе — коллизионные фикстуры (термин словаря внутри backticks; фонетический сосед в пути).
**Запись происхождения** в памяти `{raw, afterDictionary, final}` на последнюю диктовку (без диска, независимо от тумблеров).

- (а) Порт: `quality/cleanup/` — спека контракта, 28 фикстур (адаптация под наш словарный блок), Python-раннер (HTTP → subprocess к `polish-cli` в DictationCore), baseline детполишера записан; typography-fold в TranscriptPolisher.

Обучение: LoRA mlx_lm, **0.6B сначала**, и со своим пилотом: **смоук 100 шагов → шаги/сек → объявленный wall-clock бюджет ≤12 ч на прогон, чекпойнт каждые 200 шагов**; перерасход → сокращение пар по тому же правилу тем. Триггер 1.7B численный: **дельта к сильнейшему бейзлайну < +1.5 пп ИЛИ ≥60% остаточных ошибок «ёмкостного» типа** по предобъявленной таксономии (парафраз-дрейф, переписывание структуры). Формат: фиксированный разделитель, без системного промпта, non-instruct база.
- Гейт (б), предварительный, объявлен до генерации: primary = assertion-pass-rate; **зелёный = paired-bootstrap 95% CI дельты против сильнейшего из {raw, детполишер, промптованный instruct-бейзлайн} исключает ноль И точечная дельта ≥ +3 пп**; **правило потолка**: если сильнейший бейзлайн даёт pass-rate >94%, primary переключается на относительное сокращение error-rate (CI исключает ноль, точечное сокращение ≥15%) — объявлено до заморозки eval. **Instruct-бейзлайн запинен**: Qwen3-1.7B (instruct, mlx-community 4bit, пин ревизии), промпт = портированный контракт уровня light, temperature 0 — в eval-бандле рядом с хешированным списком бустов. Guardrails: retention/addition/typography не хуже −0.5 пп; adversarial 0/300 выполненных инструкций (Wilson upper ≈1.2%); VoiceScribe-0.8B — единственный внешний бейзлайн (Quill — verbatim-by-design, только в приложение поста). Ничья/красный → детполишер остаётся, пост = абляция.
- (в) Интеграция: SPM `LocalPolish`, протокол в DictationCore; **гейт перегоняется на точно шипящемся артефакте** (fused MLX; при fallback — квантованный GGUF); guard одношаговый veto→raw (кратный рост длины — как у wai-computer — плюс потеря идентификаторов); перф-гейт: cold+warm p50/p95, **warm p50 ≤400 мс, p95 ≤800 мс, peak-RSS дельта ≤700 МБ**; e2e stop→insert с полировкой; **бенчмарк-барьер: замеры только без фоновых тренировок**; выключенный тумблер = путь не исполняется (тест). Докачка opt-in; **default-OFF всю волну**; M1/M4-mini замер — слот в release-evidence (человеческий). Язык приватности/сети в README/лендинге обновляется в том же PR (вторая модель = та же кнопка ModelStore).

**W8. Замеры и материалы.**
