Вторая публичная бета — продукт вырос на порядок.

- Живой предпросмотр: слова появляются на панели, пока вы говорите
- Правка последней диктовки учит словарь — и текстовые замены, и акустику
- Выбор языка распознавания: Automatic и 29 языков движка
- Акустический подсказчик терминов: смешанная русско-английская речь заметно точнее
- Плотная речь (300+ слов в минуту) больше не теряет хвосты
- Текст после отпускания клавиши приходит на треть быстрее
- Сигнал старта играет только после первого записанного кадра — первое слово не срезается
- Клавиша объясняет неготовность, ошибки оседают в меню, значок сигналит о спасённом тексте
- Автозапуск при входе, выключатель предпросмотра, подтверждение удаления модели
- Полсотни исправлений из трёх независимых ревизий
