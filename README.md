# Wai Dictation

Диктовка для Mac, которая работает целиком на вашем компьютере.

Нажали клавишу → сказали → отпустили → текст появился там, где стоял курсор. В любом приложении.

> Статус: публичная бета. Свежий образ — [v0.2.0-beta.1](https://github.com/mikwiseman/wai-dictation/releases/tag/v0.2.0-beta.1), подписан Developer ID и нотаризован; страница загрузки — [wai.computer/dictation](https://wai.computer/dictation/). Обновления приходят через Sparkle: установленная бета сама предложит новую версию.

## Почему локально

Речь распознаётся моделью, которая лежит на вашем диске. Аудио никуда не отправляется — приложение работает в самолёте.

**Приложение выходит в сеть только по вашей команде:**

| Когда | Куда | Что узнаёт вторая сторона |
|---|---|---|
| Вы нажали «Скачать модель» | Hugging Face CDN; при отказе — GitHub Releases mirror | IP-адрес, факт загрузки |
| Вы включили проверку обновлений | GitHub Pages — файл со списком версий | IP-адрес, версия приложения |
| Вы согласились установить обновление | GitHub Releases — сам образ | IP-адрес, факт загрузки |

Проверка обновлений по умолчанию **выключена**. Включается вручную: Настройки → Основное → Обновления. Пока она выключена, приложение само в сеть не ходит — ни при запуске, ни в фоне.

Больше ничего. Ни аккаунтов, ни аналитики, ни отчётов об ошибках, ни сторонних SDK.

Это не обещание, а проверка. Распознавание запускается в песочнице с полностью запрещённой сетью и обязано выдать текст:

```bash
./scripts/test-zero-network.sh
```

```
→ Собираю инструмент
Build of product 'asr-bench' complete! (0.21s)
→ Запускаю распознавание в песочнице без сети
  Модель загружена за 0.11 с

  === probe.wav ===
  Проверка работы без интернета.

Пройдено: речь распознана при полностью запрещённой сети.
```

Скрипту нужна уже скачанная модель — он проверяет то, что происходит после загрузки. Без неё скрипт скажет об этом и выйдет с кодом 69.

## Проверьте сами

Обещания стоят ровно столько, сколько стоит их проверка. Локальность закрывают три независимых gate: sandbox deny с положительным control-connect, process-attributed tracer без песочницы и статический scan сетевой поверхности.

| Что проверяется | Чем | Сколько занимает |
|---|---|---|
| Сеть не вызывается нигде, кроме заявленных двух мест | `./scripts/check-network-surface.sh` | доли секунды |
| Распознавание работает при полностью запрещённой сети | `./scripts/test-zero-network.sh` | около секунды, нужна модель |
| Runtime не делает DNS/connect/send без песочницы | `./scripts/test-zero-network-trace.sh` | около секунды, нужна модель |
| Диктовка работает **на вашем голосе**, и вот цифры | `./scripts/self-check.sh` | пара минут, нужен микрофон |
| Клавиша, вставка, защищённый ввод, буфер обмена | [docs/manual-check.md](docs/manual-check.md) | десять минут руками |

Статический scan выполняется в каждом CI. Оба runtime network-gate обязательны для release и требуют уже установленной модели. Проверку своего голоса и installed-app matrix за вас не сделает CI: микрофон, разрешения и чужие приложения доступны только человеку за этим компьютером.

`self-check.sh` попросит сказать две фразы — обычную русскую и русскую с английскими терминами, — запишет их с микрофона, распознает и покажет эталон и результат рядом. Расхождение считает тот же скорер, что и [замеры](docs/benchmarks.md), поэтому ваша цифра сравнима с их 2,0% и 26,9%, полученными на синтезированной речи. Заодно он замерит задержку и проверит, что микрофон отпущен. В конце — сводка, которую можно целиком вставить в issue.

Записи удаляются сразу после распознавания. Всё, что проверить не удалось, скрипт называет вслух отдельным списком: непроверенное, о котором промолчали, читается как проверенное.

## Про клавиатуру — честно

Приложению нужно разрешение «Универсальный доступ» (Accessibility). Оно даёт две вещи: увидеть вашу горячую клавишу в любом приложении и вставить готовый текст.

Это значит, что системный монитор событий технически получает нажатия клавиш. Мы их **не логируем, не сохраняем и никуда не передаём** — код сравнивает событие с выбранной горячей клавишей и с Escape, всё остальное отбрасывает, не читая. Проверить можно здесь: [`GlobalHotkeyMonitor`](apps/macos/WaiDictation/System/GlobalHotkey.swift).

Разрешение «Мониторинг ввода» (Input Monitoring) приложению **не требуется**: код спрашивает систему только про `AXIsProcessTrusted()`.

## Что оказывается на диске

| Что | Где | Сколько живёт |
|---|---|---|
| Модели распознавания и подсказчика | `~/Library/Application Support/WaiDictation/Models` | Пока не удалите: Настройки → Модель |
| Запись текущей диктовки | `~/Library/Application Support/WaiDictation/Takes` | Удаляется сразу после распознавания |
| Recovery-запись после технической ошибки | `~/Library/Application Support/WaiDictation/RecoveredAudio` | До 10 WAV, до 7 дней и до 1 ГиБ |
| Текст, который не удалось вставить | Только память процесса | До следующей диктовки или выхода из приложения; доступны Copy/Retry |
| Настройки и словарь замен | `defaults` приложения | Пока не удалите приложение |

Активные и recovery-записи исключены из резервных копий. Успешные диктовки и распознанный текст на диск не записываются. Recovery-WAV появляется только после технической ошибки или прерывания, всегда виден в меню и удаляется после успешного Retry либо по кнопке Delete.

Чтобы убрать всё, достаточно удалить приложение и папку `~/Library/Application Support/WaiDictation`.

## Как пользоваться

- **Удерживайте** горячую клавишу, говорите, отпустите — текст вставится.
- **Двойное нажатие** включает режим без удержания: запись идёт до следующего нажатия.
- **Escape** отменяет диктовку, пока она идёт. В остальное время это обычная клавиша.
- Одна диктовка длится не больше часа; на пределе записанное распознаётся и вставляется.
- Текст вставляется через буфер обмена и ⌘V. Прежнее содержимое снимается в память байт-в-байт — включая служебные типы браузеров и мессенджеров, — возвращается на место не позже чем через две секунды и лишь пока clipboard принадлежит приложению. Не трогаются только пароль из менеджера паролей (concealed), file promises и содержимое больше 16 МиБ: вместо вставки доступны Copy/Retry.
- Временная запись диктовки ограничена текущим Mac. В beta непрерывность предыдущего элемента Universal Clipboard после транзакции не гарантируется.

## Требования

- macOS 14 или новее
- Mac на Apple Silicon. DMG и все Mach-O собираются только для `arm64`; Intel не поддерживается
- 586 МБ на диске под две модели: распознавание (483,1 МБ) и акустический подсказчик терминов (102,8 МБ), всего 37 файлов. На время установки нужно около 700 МБ свободного места: файлы сначала скачиваются во временную папку и только потом переезжают на место

Обе модели скачиваются один раз с зафиксированных ревизий репозиториев, и контрольная сумма каждого файла сверяется до установки. Половинчатая установка никогда не считается рабочей.

## Сборка из исходников

Нужен Xcode с тулчейном Swift 6. XcodeGen загружается скриптом в зафиксированной версии и проверяется по SHA-256; Homebrew для воспроизводимой сборки не нужен.

```bash
git clone https://github.com/mikwiseman/wai-dictation.git
cd wai-dictation

# Логика — быстрые тесты, модель не нужна
swift test --package-path Packages/DictationCore
swift test --package-path Packages/LocalASR

# Само приложение
"$(./scripts/pinned-xcodegen.sh)" generate --spec apps/macos/project.yml
xcodebuild -project apps/macos/WaiDictation.xcodeproj -scheme WaiDictation \
  -destination 'platform=macOS,arch=arm64' CODE_SIGNING_ALLOWED=NO build
```

Собранное приложение нужно запустить из Finder и выдать разрешения — микрофон и универсальный доступ. Дальше окно первого запуска доведёт до первой продиктованной фразы.

Пробный DMG: `./scripts/build-dmg.sh`. Он собирает отдельное
`Wai Dictation Dev` с bundle id `is.waiwai.dictation.dev`, поэтому не ломает и не
засоряет разрешения production-приложения.
